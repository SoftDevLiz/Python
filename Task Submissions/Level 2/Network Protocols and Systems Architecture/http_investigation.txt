POST Request:
Invoke-WebRequest -Uri "https://httpbin.org/post" -Method Post -ContentType "application/x-www-form-urlencoded" -Body "key=value"  


























POST vs GET:


* GET is primarily used to request or retrieve data from a server, and the parameters are usually visible in the URL.
* POST is used to send or "post" data to a server to be processed, such as submitting a form or uploading a file.


Unlike GET, a POST request includes a body (payload) that contains the data being sent.


 The Purpose of the Payload (key=value):
* Purpose: The payload is the actual information you want the server to process. In this case, key=value is a simple piece of data representing a form field and its input.
* Transmission: This data is transmitted in the body of the HTTP message, not the header . Because it is in the body, it is handled separately from the URL and request metadata.
Observing the Response Body:
When you run the POST command to httpbin.org/post, the server sends back a JSON response:
 "args": {},
                      "data": "",
                      "files": {},
                      "form": {
                        "key": "value"
                      },
